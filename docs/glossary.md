# ユビキタス言語定義(用語集)

プロジェクト内で使われる用語を統一し、ドキュメント・コード・会話での認識のズレを防ぐ。

## 1. ドメイン用語・ビジネス用語

| 日本語 | 英語(コード上の命名) | 定義 |
|---|---|---|
| ルート | Route | ユーザーが地図クリック(またはGPX)で作成した、地点の連なり全体 |
| 経由地点 | Waypoint | ユーザーが地図クリックで追加した地点(GPXの場合はトラックポイント)。緯度・経度を持つ |
| 地点 | RoutePoint | 断面図を構成する1つの座標。経由地点と補間点の両方を含み、緯度・経度・標高・累積距離を持つ |
| 補間点 | Interpolated Point | 経由地点間を直線で結び、サンプリング間隔ごとに生成した地点 |
| サンプリング間隔 | Sampling Interval | 補間点を生成する距離の間隔(初期値50m) |
| 断面図 | Elevation Profile | 累積距離を横軸、標高を縦軸としたルートの標高変化を表す折れ線グラフ |
| 標高 | Elevation | ある地点の海抜高度(メートル) |
| 累積距離 | Distance From Start | ルートの起点から、その地点までの経路に沿った距離の合計 |
| 総距離 | Total Distance | ルート全体の距離の合計 |
| 獲得標高 | Total Ascent | ルート全体で標高が上昇した量の合計値。画面上の表示は「総上り」 |
| 累積下降量 | Total Descent | ルート全体で標高が下降した量の合計値。画面上の表示は「総下り」 |
| 上り / 下り | Uphill / Downhill | 標高が上がる区間 / 下がる区間。表記は漢字の「下り」に統一する(「くだり」とは書かない) |
| 平滑化 | Smoothing | 標高のノイズを除くため、各地点の標高を前後の地点との移動平均で置き換える処理 |
| 判定閾値 | Threshold | 上り/下りとして計上する最小の標高変化量(初期値3m)。これ未満の変化はノイズとみなす |
| サマリー | Summary | 総距離・獲得標高・累積下降量をまとめた要約表示 |

## 2. UI/UX用語

| 日本語 | 英語(コード上の命名) | 定義 |
|---|---|---|
| 地図エリア | Map View / MapView | ユーザーがクリックしてルートを作成する地図表示部分 |
| 1つ戻す | Undo Last Point | 直前に追加した地点を1つ削除する操作 |
| リセット | Reset Route | 作成中のルートをすべて削除し、最初からやり直す操作 |
| GPXアップロード | GPX Upload | GPXファイルを読み込んでルートを作成する操作(次期実装) |

## 3. 技術用語

| 日本語 | 英語 | 定義 |
|---|---|---|
| DEM | DEM(Digital Elevation Model) | 標高を格子状のデータとして持つ数値標高モデル |
| DEMタイル / 標高タイル | DEM Tile | 国土地理院が提供する、DEMをPNG画像のタイルとして配信したもの。ピクセルのRGB値から標高を算出する |
| 双線形補間 | Bilinear Interpolation | 周囲4つの格子点の値から、その間にある地点の値を求める計算方法 |
| 地図タイル | Map Tile | 地図を格子状に分割した画像データ。国土地理院タイルを利用 |
| GPX | GPX(GPS Exchange Format) | GPS機器やアプリでよく使われる、経路情報を記録するXML形式のファイル |
| ハバーサイン公式 | Haversine Formula | 緯度経度から2点間の球面上の距離を計算する公式 |

## 5. コード上の命名規則(再掲・要点)

詳細は `development-guidelines.md` を参照。本用語集の英語表記をベースに、
JavaScript変数・関数はcamelCase(例: `calculateTotalAscent()`)、
CSSクラスはkebab-case(例: `.elevation-chart`)で命名する。
