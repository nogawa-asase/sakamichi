# 初回実装 タスクリスト

`design.md` の「4. 実装アプローチ」に従い、データが流れる順(環境構築→地図→補間→標高取得→計算→描画→仕上げ)
に実装する。各タスクの完了条件は `requirements.md` の受け入れ条件に対応する。

## 0. 開発環境構築

- [ ] `package.json` を作成し、devDependenciesに `eslint`, `typescript` を追加
- [ ] `npm scripts` に `lint`(`eslint .`)、`typecheck`(`tsc --noEmit`)を定義
- [ ] `eslint.config.js` を作成(ES2015以降・ブラウザ環境・`sourceType: module`)
- [ ] `jsconfig.json`(`checkJs: true`)を作成し、`js/`配下を型チェック対象にする
- [ ] `.gitignore` に `node_modules/` を追加
- [ ] リポジトリルートに `.nojekyll` を追加
- [ ] `npm install` を実行し、`npm run lint` / `npm run typecheck` が(対象ファイルなしで)通ることを確認

**完了条件**: 空のプロジェクトに対して lint・typecheck が正常終了する

## 1. 画面の骨組み

- [ ] `index.html` を作成(タイトル、地図エリア、断面図エリア、取得中インジケータ、
      対象外エリア通知欄、サマリー、操作ボタン、フッター(出典表示))
- [ ] Leaflet・Chart.jsをCDN(バージョン固定 + SRI)で読み込む
- [ ] `css/style.css` を作成(Flexboxで縦積みレイアウト、CSSカスタムプロパティで色・余白定義)
- [ ] 簡易HTTPサーバーでブラウザ表示を確認(レイアウト崩れ・コンソールエラーがないこと)

**完了条件**: 静的な画面(地図・グラフはまだ空でよい)がエラーなく表示される

## 2. 地図表示・経由地点の入力(MapView)

- [ ] `js/mapView.js` を作成し、Leafletで国土地理院地図タイルを表示する
- [ ] 地図クリックでマーカーを追加し、経由地点間を線で結ぶ
- [ ] 「1つ戻す」ボタンで直前のマーカー・線を削除する
- [ ] 「リセット」ボタンで全マーカー・線を削除する
- [ ] `js/main.js`(AppController)に地図からのクリック通知を受け取る最小限の骨組みを作り、
      `route.waypoints` に経由地点が正しく追加/削除されることをコンソールログ等で確認する

**完了条件**: requirements.mdの「地図クリックでマーカー追加」「1つ戻す」「リセット」の項目を満たす

## 3. 区間補間(RouteSampler)

- [ ] `js/routeSampler.js` を作成し、2点間を50m間隔で補間して `RoutePoint[]`(elevation: null)を生成する関数を実装
- [ ] `main.js` から、追加された区間のみを渡して呼び出し、`route.points` に反映する
- [ ] 地図上に補間点自体は描画しないことを確認する

**完了条件**: 経由地点を2つ置いたとき、`route.points` に距離50m間隔の点が生成される(デバッグ表示等で確認)

## 4. 標高取得(ElevationService)

- [ ] `js/elevationService.js` を作成
  - [ ] 緯度経度→タイル座標・ピクセル位置への変換関数
  - [ ] タイル画像の取得・デコード(`crossOrigin="anonymous"` + canvas + `getImageData`)
  - [ ] ピクセル値→標高値の変換式の実装
  - [ ] 5A→5B→10Bのフォールバック処理
  - [ ] 周囲4ピクセルの双線形補間(無効値を除外する処理を含む)
  - [ ] タイルのメモリキャッシュ(`Map`)
  - [ ] 同時取得数を6に制限するキュー
- [ ] `main.js` から `route.points` の該当区間を渡し、非同期で標高を取得・反映する
- [ ] 既知の地点(例: 富士山山頂付近の座標)で標高値が概ね妥当であることを手動確認する
- [ ] 海上の座標でも例外で落ちず、`elevation: null` になることを確認する

**完了条件**: requirements.mdの「地点間の起伏が断面図に反映される」「対象外エリアでエラーにならない」の前提となる標高データが取得できる

## 5. 距離・獲得標高の計算(DistanceCalculator)

- [ ] `js/distanceCalculator.js` を作成
  - [ ] Haversine公式による2点間距離・累積距離・総距離の計算
  - [ ] 標高の平滑化(前後100m移動平均、nullを除外)
  - [ ] 閾値3mによる上り/下り判定と `totalAscent` / `totalDescent` の計算
  - [ ] 区間ごとの上り/下り(`"up"`/`"down"`)判定データの生成
- [ ] `main.js` から標高取得後に呼び出し、`route` を更新する

**完了条件**: 平坦なルートでノイズによる過大な獲得標高が出ないことを手動確認する

## 6. 断面図描画(ElevationChart)

- [ ] `js/elevationChart.js` を作成し、Chart.jsで累積距離×標高の折れ線グラフを描画する
- [ ] 上り/下り区間を色分け表示する
- [ ] elevationがnullの区間は線を途切れさせる
- [ ] 取得中インジケータの表示/非表示を切り替える関数を実装する
- [ ] ルート変更のたびに再描画されることを確認する

**完了条件**: requirements.mdの断面図関連の受け入れ条件をすべて満たす

## 7. サマリー表示(SummaryPanel)

- [ ] `js/summaryPanel.js` を作成し、総距離・総上り・総下りを表示する
- [ ] ルート変更のたびに更新されることを確認する

**完了条件**: requirements.mdのサマリー関連の受け入れ条件を満たす

## 8. 非同期処理の競合対策(AppController)

- [ ] `main.js` に世代番号(`generation`)を実装し、ルート変更のたびにインクリメントする
- [ ] 標高取得開始時に世代番号を記録し、完了時に現在の世代番号と比較して不一致なら結果を破棄する
- [ ] 標高取得中に「1つ戻す」「リセット」を連続操作し、古い結果が反映されないことを手動確認する
- [ ] `route.points` に `elevation: null` が含まれる場合、対象外エリアの通知を表示する

**完了条件**: requirements.mdの非同期処理関連の受け入れ条件をすべて満たす

## 9. 結合確認・性能確認

- [ ] 一連の操作(クリック連打、1つ戻す、リセットの組み合わせ)を通しで確認する
- [ ] 曲がりくねった長距離ルート(100km程度)を作成し、性能目標を確認する
  - [ ] クリックからマーカー表示 100ms以内
  - [ ] 取得済みタイル範囲での更新 1秒以内
  - [ ] 100kmルートの初回表示 10秒以内
- [ ] Chrome / Safari / Firefox / Edgeの最新版で動作確認する
- [ ] ブラウザコンソールにエラーが出ないことを確認する

**完了条件**: requirements.mdの性能・品質関連の受け入れ条件をすべて満たす

- [ ] `npm run lint` / `npm run typecheck` をエラーなく通す
- [ ] GitHub Pagesの公開設定(リポジトリルート/mainブランチ)を行う(リポジトリ所有者が実施)
- [ ] 公開URLでの動作確認
- [ ] `README.md` に公開URLを追記
- [ ] `.steering/20260922-initial-implementation/` の内容を最新化してコミット

**完了条件**: requirements.mdの「GitHub Pages上の公開URLで動作する」を満たし、プロダクトの成功の定義を達成する
